# 彦根城さんぽ

国宝・彦根城（滋賀県彦根市）の天守と城下を、スマホで歩いて巡れる3D散策アプリの試作品。three.js製の単一HTMLです（「大阪城さんぽ」と同じ仕組み）。

- 時代を選ぶ（メニューの「時代」）: 現代 / 江戸時代（19世紀前半ごろの想像復元）
- 彦根山: 南から 鐘の丸 → 大堀切（廊下橋）→ 天秤櫓・太鼓丸（時報鐘）→ 太鼓門櫓 → 本丸（天守・着見台）→ 西の丸（三重櫓）→ 出曲輪・山崎曲輪。山の斜面は林で、曲輪は石垣（野面積み・出隅の算木積み）で囲まれています。登り石垣もあります
- 登城の道: 表門橋 → 表門山道 / 大手門橋 → 大手山道。どちらも大堀切の底に着き、鐘の丸へ上って廊下橋を渡り、天秤櫓へ。西の丸から山崎曲輪・黒門へ下る石段もあります
- 天守（国宝）: 三重三階、附櫓・多聞櫓つき。切妻・千鳥・唐破風、2・3階の花頭窓、3階の高欄。附櫓の戸口から入り、急な階段で1階〜3階（最上階）まで上れます
- 現存の建物: 天秤櫓・太鼓門櫓・西の丸三重櫓・佐和口多聞櫓・馬屋・能舞台・玄宮園（臨池閣・鳳翔台）・楽々園・埋木舎
- 江戸時代だけ: 表門・大手門・京橋口・佐和口・黒門・山崎門などの櫓門と枡形、曲輪をめぐる土塀、着見櫓・宝蔵・鐘の丸や出曲輪の櫓・山崎曲輪三重櫓、表御殿、槻御殿、二の丸の家老屋敷と米蔵、松原内湖と外堀、本町の町並みと人々
- 入れる建物: 現代＝彦根城博物館・馬屋・開国記念館・埋木舎・楽々園・キャッスルロードの店 / 江戸時代＝表御殿の大広間・御座之間・馬屋・佐和口多聞櫓・埋木舎・槻御殿・本町の商家・家老屋敷の書院
- 段差は約1.3mまでしか上り下りできません（石垣や橋から落ちません）。廊下橋の下の堀切も歩けます
- 人物・調度品の切り抜き画像（assets/atlas*.webp）と、襖絵・天井の画像（assets/tiles.webp）は「大阪城さんぽ」と共通です
- 名所の写真は Wikimedia Commons から検索して表示します（撮影者・ライセンスを併記）
- 距離は実際より縮め、建物の配置と寸法も簡略化しています。江戸時代の姿は絵図などをもとにした想像を交えた復元です

URLの末尾に `?era=edo` を付けると江戸時代から始まります。

公開URL（GitHub Pages を有効にした場合）: https://32miya.github.io/32miya-32miya-hikone-castle/

## お城さんぽシリーズ共通
- 人物・旗・襖絵・床板・石垣などの素材は、シリーズ共通の `https://32miya.github.io/oshiro/common/assets/` から読み込みます（このリポジトリに同じ画像を置かない）。一覧と使い方は `32miya/32miya.github.io` の `oshiro/common/README.md`。
- 天守の窓は本当の開口にして、各階の中から外の景色が見えるようにする（シリーズ共通の作り）。
- index.html の末尾の `oshiro-portal:begin`〜`end` は「お城選びへ戻る」ボタンなので消さない。
- 彦根城専用の調度品・襖絵（屏風・燭台・蒔絵の箱・掛軸・床の間・伊万里の壺・甲冑・長持・座卓・石灯籠・松・鬼瓦、襖絵の松・桜・鶴・竹）は、このリポジトリの `assets/hk_spr.webp` に置いています。
